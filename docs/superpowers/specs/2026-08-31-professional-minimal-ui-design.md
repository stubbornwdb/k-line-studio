# K-Line Studio 专业极简 UI 设计

## 目标

将当前单页行情工作台重构为更适合长期盯盘和复盘的专业极简界面。重点改善中文字体可读性、信息层级、工具条密度、右侧面板扫描效率，以及窄屏布局，不改变现有行情、收藏、提醒、笔记、缓存、批量拉取和全屏图表能力。

## 视觉方向

- 默认采用暖灰浅色主题，保留深色主题切换；已有用户的主题偏好继续保留。
- 使用适合中文阅读的无衬线字体栈，价格、涨跌幅、时间和统计数字使用等宽字体。
- 降低大面积蓝色填充。蓝色仅用于选中状态、链接和关键操作；涨跌颜色保持红涨绿跌。
- 使用细边框、浅色底、左侧状态线和短下划线表达层级，避免卡片套卡片和大量胶囊按钮。
- 动效只用于首次进入、数据更新和面板切换，时长短且不影响盯盘。

## 页面骨架

### 应用栏

顶部固定为约 56px 的应用栏，包含品牌、交易所选择、交易对搜索、收藏状态和侧栏开关。应用栏只承载当前市场上下文与全局入口。

### 行情头部

图表上方展示当前交易对、最新价、24H 涨跌、24H 高低、成交额和数据更新时间。最新价和涨跌幅具有最高视觉权重，其余指标以统一的标签和值对齐。

### 图表工具栏

工具栏按上下文分组：周期与区间属于行情上下文，指标/画线/显示属于图表操作，刷新/全屏/主题属于系统操作。窄屏下工具组允许横向滚动，不把按钮压缩到不可读。

### 右侧工作面板

保留当前右侧面板并固定在约 320px 宽度，包含“笔记 / 缓存 / 盯盘”三个主标签。盯盘内部使用细分 tab 切换“收藏 / 次新币 / 涨幅榜 / 跌幅榜”。列表行左右对齐交易对、价格和涨跌幅，当前交易对增加左侧状态线。

次新币筛选使用单行紧凑控件：时间范围、排序、搜索和批量拉取。空间不足时允许横向滚动，禁止筛选项无约束换行造成错位。保留分页/滚动批量加载行为。

### 窄屏行为

当视口不足以容纳图表和右侧面板时，右侧面板转为底部抽屉，图表保持优先展示。应用栏和工具栏允许横向滚动，核心价格和刷新状态始终可见。

## 交互要求

- 选中状态使用细边框、浅色底或短下划线表达，避免高饱和大色块。
- 收藏按钮使用星标，提醒按钮使用铃铛，图标按钮提供 tooltip。
- 刷新控件显示下次刷新倒计时；刷新中显示明确 loading 状态；历史区间显示暂停状态。
- 交易对切换必须重置图表尺寸与可见范围，不能要求手动刷新浏览器。
- 保持全屏图表、图形绘制、笔记、复盘、收藏、提醒和次新币批量拉取功能。

## 技术范围

- 主要修改全局 tokens、Tailwind 字体配置和共享 UI 基础组件。
- 重构 `TopBar`、`MarketStrip`、`ChartToolbar`、`ChartLegend`、`MonitorPanel` 及 `App` 中的布局 class。
- 不修改行情接口、缓存逻辑、图表数据协议和次新币查询协议。
- 默认主题仅影响新会话；已持久化的主题选择不被强制覆盖。

## 验收标准

- `frontend` typecheck 与 production build 通过。
- 桌面宽度下，顶部、行情头部、工具栏、图表和右侧面板层级清晰且无重叠。
- 窄屏下，右侧面板可作为底部抽屉使用，图表不被挤压到不可读。
- 切换交易对后图表立即显示正确数据和可见范围。
- 次新币的时间范围、排序、搜索、滚动加载和批量拉取仍可用。
- 刷新频率、倒计时、手动刷新、全屏和主题切换均可操作。
